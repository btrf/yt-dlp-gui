Features

Everything you need to download video and audio — and nothing extra.

Sites supported by yt-dlp

YouTube, VK, OK, Twitter/X, TikTok, Instagram, Dailymotion, Reddit and thousands more — full coverage inherited from yt-dlp.

Video and audio

Save full videos or extract the sound as MP3/M4A.

Quality and format

Pick a quality preset and set a specific format.

Playlists

Download a whole playlist, only the first or last item, a range or selected items.

Filename template

Set your own template, e.g. %(title)s [%(id)s].%(ext)s, and keep files the way you want.

No ad breaks

Sponsor segments are cut out of the video via SponsorBlock — enabled by default, one checkbox to turn off.

Extra arguments

Pass any yt-dlp flags manually if you need non-standard behaviour.

Batch download from file

Import a .txt list of links — the app downloads them one by one in a single run.

Installation and launch

No installation required — the app runs as a single file.

  1. Download yt-dlp-gui-portable-vX.X.X.exe from the releases page.
  2. Save the file into any folder, e.g. C:\Downloads\.
  3. Run the .exe.
  4. Paste a video link or import a link list from a file and press "Download".

How to use

Four steps — and the file is on your disk.

1

Paste a link

Copy the address of the page with the video and paste it into the Source field.

2

Choose options

Type (video/audio), quality, format, filename template and extra arguments.

3

Start the download

Press "Download" — progress updates in real time.

4

Grab the file

The finished file lands in the Downloads folder or wherever you pointed it.

Playlists and link lists

Tick "Download playlist" to enable scope selection: the whole list, the first or last item, a range or specific numbers. The import button accepts a plain text file with links — every line is processed in order.
